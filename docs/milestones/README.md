# QE Agent Implementation Milestones

This directory records the implementation assignments and significant
reviews used to build the QE Agent incrementally.

Each milestone should normally contain:

- implementation assignment;
- significant independent review findings;
- correction assignment when required.

These documents are historical implementation records.
